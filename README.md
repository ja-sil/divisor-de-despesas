# Divisor de Despesas (Python)

Sistema modular para controle e divisão justa de gastos em viagens e eventos.

* **Módulos:**
* `main.py`: Fluxo principal da aplicação.
* `participantes.py`: Cadastro e validação do grupo.
* `despesas.py`: Registro dos pagamentos por categoria e valor.
* `calculos.py`: Processamento de totais, cota média e saldos (+ a receber / - a pagar).
* `relatorios.py`: Exibição do extrato final no terminal.


* * **Execução:** `python main.py`
